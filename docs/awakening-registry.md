# Æclyptic Awakening Registry v1

## Purpose and fiction boundary

An original worldbuilding system for CinemaSwarm Season 01. The registry
**does not claim** actual eclipses, solar storms, meteorites, nuclear exposure,
epigenetic responses, trauma or gut–brain signaling cause superpowers, mutate
humans beneficially or generate an organic AI companion.

The DNA LLM is the fictional linguistic interface of emergent metacognition.
Its presentation is a privately perceived waking-dream system. Synesthesia
is one **explanation for cross-sensory rendering**, not a substitute for the
system. The fictional companion can manifest as dialogue within that system.

Real biological analogies:
- Noncoding DNA includes important regulatory sequences and RNAs; not every
  noncoding region has an established function.
- Gene expression is context-dependent; stress changes physiology but does
  not reliably grant abilities.
- The gut–brain axis connects enteric, autonomic, central nervous, hormonal,
  microbial and immune signaling. It does not establish the solar/celiac
  plexus as a generator of dreams.
- Ionizing radiation often damages DNA and increases health risks. Exposure
  is **not an advisable activation pathway**.
- Ordinary eclipses and planetary configurations do not provide a verified
  biological unlocking signal.

## Schema and provenance

The author-reviewed registry includes:
- `cosmology_sha256`, `world_id`: immutable binding to the existing
  Cosmological Context Engine, not a competing simulator
- `mechanism`: explicitly fictional field, regulatory analogy, neural and
  somatic analogies, and scientific boundary statement
- `triggers`: classified celestial, environmental, or endogenous events;
  UTC time, geometry, radiant influence, exposure description, fiction-only
  effect, provenance and a **fictional world law**
- `hosts`: individual susceptibility, lived context, gut-brain role,
  waking-dream system presentation, companion identity, optional modes
  (synesthetic, somatic, inner dialogue), limited capacities and approvals
- `transitions`: author-approved, causally linked state changes:
  `dormant -> primed -> emergent -> articulate -> integrated`
- `review`: author approval evidence.

A trigger never causes automatic activation: a host with no approved
transition remains dormant. Host state cannot jump phases or move backward
without a separately designed future schema. The model allows failed or
unstable activation, and does not require trauma.

Time-bound records and chronological provenance prevent foreshadowing from
being mistaken for a prior event. The companion remains the same tracked
character in each observed state; observational access is not omniscience.

## CLI

```bash
python cinema_swarm.py --observe-awakenings \
  --awakening-cosmology ./private/cosmology.json \
  --awakening-registry ./private/awakenings.json \
  --awakening-output ./private/awakening-observer.json

python cinema_swarm.py --cosmology-context ./private/cosmology.json \
  --awakening-registry ./private/awakenings.json --dry-run
```

Live calls require `--approve-cosmology-brief` and
`--approve-awakening-brief`; an accompanying canonical world snapshot also
requires its existing separate authorization. No third-party API call is made
by either offline observation or dry-run.

## Quality and further work

This is a deterministic narrative contract with tests, not a clinical
epigenetics model, physics calculation, biological simulator, or proof
of autonomous intelligence. Future episodes can bind scene/shot outputs
to this registry via explicit host and companion IDs and validated state
snapshots. No private Dreamcorp or agent canon is published.
